OpenDocument

Czytnik dokumentów i edytor PDF

PDF, DjVu, EPUB, FB2, DOCX, ODT, RTF, Markdown i HTML w jednej aplikacji. Tryb książki, adnotacje zgodne ze standardem PDF, podpisy i formularze.

  • Bez reklam

  • Aktualizuje się sama

Co potrafi

  • Wiele formatów

    PDF, DjVu, EPUB, FB2, DOCX, ODT, RTF, Markdown, HTML i obrazy.

  • Tryb książki

    Dwie strony obok siebie, także na składanych telefonach.

  • Adnotacje

    Zakreślenia, notatki i rysunki zapisywane w standardzie PDF.

  • Formularze i podpisy

    Wypełnianie formularzy i podpisywanie dokumentów.

  • Edycja PDF

    Porządkowanie stron i zapis zmian jako nowy plik.

  • Oryginał bez zmian

    Twój plik pozostaje nietknięty.
